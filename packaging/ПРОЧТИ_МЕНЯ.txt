MangaTranslator — портативная сборка (Windows, без установки Python)
====================================================================

Что это
-------
Перевод китайской манги/комиксов на русский:
  * расширение для Chrome — рисует перевод прямо поверх картинок на сайте;
  * приложение — читает страницы, переводит их и слушает расширение.


Как запустить (2 шага)
----------------------
1. Запустите MangaTranslator.exe (двойной щелчок).
   Откроется окно «Manga Translator — панель управления».
   Приложение сразу поднимает мост: ws://127.0.0.1:8770/ws
   Свернуть в трей можно крестиком, приложение продолжит работать.

2. Подключите расширение к Chrome (один раз):
   * откройте chrome://extensions
   * включите «Режим разработчика» (переключатель справа сверху)
   * нажмите «Загрузить распакованное расширение»
   * выберите папку extension, которая лежит рядом с MangaTranslator.exe
   * откройте главу манги и нажмите Ctrl+Shift+Y

Готово: карточки с переводом появляются поверх баблов.


Настройка перевода (один раз)
-----------------------------
Приложение не содержит ключа API — его нужно ввести своему провайдеру:
  * в окне приложения: кнопка «Настройки» → раздел «Перевод»;
  * выберите провайдера, вставьте ключ, нажмите «Загрузить модели» и
    «Проверить связь», затем «Сохранить».
Без ключа приложение запустится, но переводить не сможет.


Режимы отображения
------------------
В попапе расширения (иконка на панели Chrome):
  * «Карточки» — плашка с переводом рядом с каждым баблом;
  * «Вшить в картинку» — китайский текст стирается, русский вписывается
    прямо в бабл.
Горячая клавиша Ctrl+Shift+Y включает и выключает перевод на странице.


Что где лежит
-------------
MangaTranslator.exe      само приложение (Python внутри, ставить ничего не нужно)
_internal\               библиотеки приложения (не удаляйте и не переносите по одной)
extension\               расширение для Chrome (его выбирают в chrome://extensions)
ПРОЧТИ_МЕНЯ.txt          этот файл

Настройки, кэш переводов и логи (создаются при работе):
  %LOCALAPPDATA%\MangaTranslator\
    config.json          настройки, в том числе ключ API
    cache\pages.db       кэш переводов (можно удалять — просто переведётся заново)
    logs\app.log         журнал: сюда смотреть, если что-то не работает


Если что-то не работает
-----------------------
* В расширении написано «Перевод: нет связи» — приложение не запущено или
  занят порт. Запустите MangaTranslator.exe; адрес и статус видны в окне
  приложения, блок «Расширение для браузера».
* Порт 8770 занят другой программой — тогда мост займёт следующий свободный
  (8771, 8772, ...). Посмотрите фактический адрес в том же блоке и укажите
  этот порт в попапе расширения (поле «Порт приложения» → «Сохранить»).
* Перевод не появляется, карточки пустые — проверьте ключ API в «Настройках»
  и нажмите «Проверить связь»; подробности всегда есть в logs\app.log.
* Chrome 137 и новее не грузит расширения из командной строки — только через
  chrome://extensions, как в шаге 2.


Проверка работоспособности сборки (по желанию)
----------------------------------------------
Откройте командную строку в этой папке и выполните:
    MangaTranslator.exe --selftest
Код возврата 0 и строки [PASS] в выводе означают, что OCR, перевод,
наложение перевода и панель управления на этом компьютере работают.

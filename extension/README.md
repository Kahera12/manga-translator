# MangaTranslator Bridge — расширение Chrome

Расширение связывает открытую страницу чтения манги с локальным приложением
**MangaTranslator** по WebSocket: оно отправляет приложению список картинок
страницы и рисует полученный перевод прямо поверх изображений.

---

## Установка

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `extension` (та, в которой лежит `manifest.json`).
5. Расширение появится в списке и на панели Chrome.

После любого изменения файлов нажмите значок обновления на карточке расширения
в `chrome://extensions`.

> Chrome 137 и новее **игнорирует** ключ командной строки `--load-extension`, а
> `Extensions.loadUnpacked` по CDP ничего не устанавливает, если браузер запущен с
> `--disable-extensions-except`. Поэтому расширение ставится вручную через
> `chrome://extensions` (как в шагах выше) — это единственный надёжный способ;
> автоматическая проверка `tools/extension_live.py` ставит его через CDP
> `Extensions.loadUnpacked` без этих ключей.

## Настройка порта

* По умолчанию расширение подключается к `ws://127.0.0.1:8770/ws`.
* Порт меняется в попапе расширения: поле **«Порт приложения»** → кнопка
  **«Сохранить»**. Значение хранится в `chrome.storage.local` под ключом `port`.
* После смены порта соединение переподключается автоматически.
* Приложение должно быть запущено **до** или **после** этого — расширение
  переподключается бесконечно с задержкой от 0.5 до 5 секунд.

## Два режима перевода

Переключатель в попапе: **«Карточки»** / **«Вшить в картинку»**.

| Режим | Что происходит |
| --- | --- |
| **Карточки** | Рядом с каждой репликой появляется полупрозрачная карточка с переводом. Карточка ставится над «пузырём» (если сверху нет места — под ним) и привязана к картинке в процентах, поэтому следует за ней при прокрутке, зуме и смене разрешения. |
| **Вшить в картинку** | Оригинальная страница подменяется переведённым изображением целиком. Для страниц, которые приложение вернуло без готовой картинки, всё равно рисуются карточки. |

## Горячая клавиша

**Ctrl+Shift+Y** — включить или выключить перевод (то же самое, что большая
кнопка **«Переводить эту страницу»** в попапе). Клавишу можно переназначить на
странице `chrome://extensions/shortcuts`.

Перевод выключен → расширение не отправляет никаких данных и полностью убирает
свой слой со страницы (и снимает свои правки стилей родительских элементов).

## Что видно в попапе

* **Подключено** / **Нет связи с приложением** и адрес `ws://127.0.0.1:<порт>/ws`;
* провайдер, модель и язык перевода, полученные от приложения (`welcome`);
* переключатель режима;
* большая кнопка включения перевода;
* прогресс: `готово X из Y` (+ очередь и число ошибок);
* поле порта с кнопкой «Сохранить».

Если приложение не запущено, попап остаётся рабочим: статус — «Нет связи с
приложением», управление переводом заблокировано, поле порта доступно.

## В странице

В правом нижнем углу появляется маленькая плашка `Перевод: 12/150` — она не
перехватывает клики и исчезает, когда перевод выключен. На странице расширение
добавляет только свои узлы (`mt-holder`, `mt-card`, `mt-inplace`, `mt-badge`);
единственное вмешательство в разметку сайта — обёртка `<div class="mt-wrap">`
вокруг картинки, если у неё нет подходящего родителя. При выключении обёртка
снимается, а исходное значение `position` родителя восстанавливается.

## Как расширение опознаёт страницы

Каждая подходящая картинка (не меньше 500×500, видимая, не наша) получает ключ —
64-битный перцептивный хеш (dHash, 16 hex-символов). Такой ключ не зависит от
URL, поэтому подмена `w720` → `w1280` и добавление `?sign=…` не сбивают
приложение с толку. Если пиксели прочитать нельзя (картинка с чужого домена без
CORS), используется запасной ключ вида `u:<origin><path>` — без строки запроса.

Список страниц отправляется целиком при каждом изменении (набор ключей, порядок,
видимость), приложение объединяет его по ключу.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| «Нет связи с приложением» | Приложение запущено? Мост включён? Порт в попапе совпадает с портом приложения? |
| Плашка `Перевод: нет связи` | То же самое; сообщение приходит со страницы. |
| Картинки найдены, перевода нет | В консоли страницы (F12 → Console) ищите строки с префиксом `[mt]`. |
| Ключи вида `u:…` | Обычное дело для картинок без CORS — приложение получает их по URL. |
| Карточки не там, где надо | Сайт использует нестандартную вёрстку; пришлите URL страницы. |

Журнал расширения: `chrome://extensions` → карточка расширения → **«Служебные
страницы»** → `background.js` (или `service worker`).

## Ограничения

* Расширение работает только в верхнем фрейме (`all_frames: false`), поэтому
  читалки, рисующие мангу внутри `<iframe>`, не поддерживаются.
* Изображения, отданные как `data:` URL или `blob:` URL, передаются/недоступны
  приложению так же, как они есть на странице.
* Сетевых запросов, кроме одного WebSocket на `127.0.0.1`, расширение не делает.
